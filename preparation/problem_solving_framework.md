# Problem Solving Framework

Use this framework for every challenge.

## 1. Understand the Problem

- What is the exact problem?
- Who is affected?
- Why is it important?
- What is the current process?

## 2. Analyze the Root Cause

Identify the main reasons behind the problem and the constraints that affect a solution.

## 3. Explore Possible Solutions

Compare multiple approaches based on feasibility, complexity, cost, scalability, and expected impact.

## 4. Select the Best Approach

Choose the solution that provides the best balance between practical implementation and measurable impact.

## 5. Build an MVP

Develop the smallest working prototype that demonstrates the core solution.

## 6. Test and Measure

Evaluate the solution using relevant metrics such as accuracy, latency, time saved, cost reduction, error reduction, or automation percentage.

## 7. Improve and Document

Record limitations, improvements, architecture decisions, results, and future work.

## Core Workflow

**Problem → Root Cause → Solution Options → Best Approach → MVP → Testing → Metrics → Improvement → Presentation**
